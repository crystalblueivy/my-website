2. Quadratic Equations Topic 02
Standard: y = ax² + bx + c
Vertex: y = a(x - h)² + k
Factored: y = a(x - p)(x - q)
Key Properties & Rules
  • Vertex Form: If a > 0, parabola opens UP (has a minimum y-value at k). If a < 0, opens DOWN (has a maximum y-value at k).
  • Factored Form: Set y = 0 to find x-intercepts directly at x = p and x = q.
  • Quadratic Formula: x = (-b ± √(b² - 4ac)) / (2a)
  • Discriminant (D = b² - 4ac):
    • D > 0: 2 Real solutions
    • D = 0: 1 Real solution
    • D < 0: 0 Real / 2 Complex solutions
  • Sum & Product of Roots:
    • Sum (r₁ + r₂) = -b / a
    • Product (r₁ · r₂) = c / a
SAT Tip: The x-coordinate of the vertex lies exactly halfway between the roots: x = -b / (2a) or (p + q) / 2.
3. Function Transformations Topic 03
y = a · f(x ± h) ± k

Rules for shifting and reflecting any base graph y = f(x):

  • Shift Up by K units: y = f(x) + k
  • Shift Down by K units: y = f(x) - k
  • Shift Left by H units: y = f(x + h)
  • Shift Right by H units: y = f(x - h)
  • Reflect over X-axis: y = -f(x) (flips vertically)
  • Reflect over Y-axis: y = f(-x) (flips horizontally)
SAT Tip: Horizontal shifts move in the opposite direction of the sign! f(x + 5) shifts left, f(x - 5) shifts right.
4. Exponential Equations Topic 04
General Form: f(x) = a · bˣ
Growth/Decay: y = a(1 ± r/100)ᵗ
Base Behavior
  • Exponential Growth: Base b > 1.
  • Exponential Decay: Base 0 < b < 1.
Percentage Formula Breakdown
  • a: Initial / Principal amount
  • r: Percent rate of increase (+) or decrease (-)
  • t: Time interval / periods
SAT Tip: Look closely at time units! If growth doubles every 3 hours, the exponent should be t / 3.
5. Exponents & Roots Topic 05
am/n = ⁿ√(aᵐ) = (ⁿ√a)ᵐ
Exponent Rules
  • Product: aᵐ · aⁿ = aᵐ⁺ⁿ
  • Quotient: aᵐ / aⁿ = aᵐ⁻ⁿ
  • Power: (aᵐ)ⁿ = aᵐᵐⁿ
  • Negative: a⁻ⁿ = 1 / aⁿ
  • Zero Exponent: a⁰ = 1
Radical Rules
  • Product: √(a · b) = √a · √b
  • Quotient: √(a / b) = √a / √b
SAT Tip: To solve radical equations, isolate the radical first before squaring both sides. Always check for extraneous solutions!
6. Circles Topic 06
(x - h)² + (y - k)² = r²
Center-Radius Form

Center is at (h, k) and radius is r.

Sector Proportions Ratio
θ° / 360° = Arc Length / 2πr = Sector Area / πr²
Circle Theorems
  • Tangent Rule: A tangent line is perpendicular to the radius at the point of contact.
  • Inscribed Angle: Measure of inscribed angle is half of central angle intercepting the same arc.
SAT Tip: If given an unformatted equation, complete the square for both x and y terms to find (h, k) and r².

8. Statistical Measures Topic 08
  • Mean: The average. Calculated by dividing the sum of all values by the count (n).
  • Median: The middle score. Order data from least to greatest; position is located at (n + 1) / 2. If n is even, take the average of the two middle values.
  • Mode: The value that appears most frequently in a data set. A set can have one mode, multiple modes, or no mode.
  • Range: Difference between maximum and minimum value (Max - Min).
  • Standard Deviation: Measures how spread out data is relative to the mean.
  • Outlier: Extreme value far from the rest; distorts the mean, but has little impact on the median.
SAT Tip: Adding an extreme outlier increases Range & Standard Deviation, pulls the Mean toward it, but leaves the Median stable.
9. Box Plots Topic 09
How to Calculate Median & Range from a Box Plot
  • Finding the Median: Look directly at the vertical line drawn inside the central box. Read the corresponding number on the number line below.
  • Finding the Range: Locate the far right end of the right whisker (Maximum) and the far left end of the left whisker (Minimum). Subtract: Range = Max - Min.
  • Finding the IQR (Interquartile Range): Subtract the value at the start of the box (Q₁) from the value at the end of the box (Q₃): IQR = Q₃ - Q₁.
SAT Tip: Each section of a box plot (left whisker, left box half, right box half, right whisker) contains exactly 25% of the total data points!
10. Experimental Design Topic 10
  • Population: The entire group under study that conclusions apply to.
  • Random Sample: Selection method where every individual has an equal selection probability; essential for generalizing findings to the whole population.
  • Sample Bias: Systematic flaw in sampling that skews data (e.g., non-random or voluntary response sampling).
  • Margin of Error: Calculated range of confidence around survey results. Increasing sample size reduces the margin of error.
SAT Tip: Results can only be generalized to the population if sample is randomly selected. Cause-and-effect can only be proven via random assignment.
11. Absolute Value Equations Topic 11
Core Concept

Absolute value represents the distance from zero on a number line, meaning distance is always non-negative (|x| ≥ 0).

Solving Rules
  • Basic Equation: |x| = a splits into two cases: x = a or x = -a (for a ≥ 0).
  • Expression inside: |ax + b| = c splits into ax + b = c or ax + b = -c.
  • Extraneous Solutions: Always plug answers back into the original equation to check for invalid results!
SAT Tip: If an absolute value equation equals a negative number (e.g., |2x + 1| = -5), there are no solutions!
12. Inequalities Topic 12
Compound & Linear Inequalities
  • Less Than ("And"): |x| < a becomes -a < x < a (bounded interval).
  • Greater Than ("Or"): |x| > a becomes x < -a OR x > a (two outer rays).
  • 2D Shading: For y ≤ f(x) shade below the line; for y ≥ f(x) shade above.
Graphing Boundary Rules
  • Strict (<, >): Dashed line on 2D plane, open circle on 1D number line.
  • Inclusive (≤, ≥): Solid line on 2D plane, closed circle on 1D number line.
SAT Tip: Always flip the inequality sign whenever you multiply or divide both sides by a negative number!
